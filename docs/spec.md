## 方案（总体架构）

系统＝**一个 monorepo 三大块**：

```
┌─ client（Vue3 + Vite + Capacitor 壳 + PixiJS 演出层）──────────────┐
│  app 壳（路由/档案切换）                                          │
│  ├─ 学习流域：关卡播放器、题型渲染、QWERTY 拼写键盘               │
│  ├─ 引擎域：调度引擎（纯函数 TS 模块，零 I/O）                   │
│  │    七池升退档判定 · 每日配比计划 · 变式选档 · 优先级截断       │
│  ├─ 演出域：PixiJS 独立画布组件（射击/怪兽/奖励演出）             │
│  ├─ 同步域：设备本地库 + 事件队列 + HLC 时钟 + 同步客户端         │
│  ├─ 内容域：词包下载/校验/缓存                                   │
│  ├─ 音频域：TTS 抽象（系统 TTS 慢速档 ⇄ 预录音库两后端）         │
│  └─ 家长域：算术门禁、周报视图、设置、词库导入向导               │
└───────────────────────────────────────────────────────────────┘
          ↑ 词包拉取（版本化不可变）   ⇅ 事件流同步（双向一次往返）
┌─ server（FastAPI + SQLAlchemy + SQLite WAL，自托管 Windows）──────┐
│  内容域：词包版本管理与分发 · 同步域：事件交换与折叠投影          │
│  家长域：周报聚合/设置/档案 · 导入域：xlsx 摄取→ECDICT 补全→      │
│  预览→入库（编制 CLI 与家长 API 共用同一管线）· 每日备份          │
└───────────────────────────────────────────────────────────────┘
```

**依赖方向（铁律）**：

1. UI → 引擎域单向依赖；引擎域是纯函数模块，**不做任何 I/O、不感知 Vue/PixiJS**——调度逻辑全部可脱离终端测试。
2. 演出域与学习流域之间**只经事件契约**通信（答题结果进、演出完成与奖励事件出），演出组件不读取题库/调度状态——这是安卓 WebView GPU 限流的风险缓冲（capacitor#3899），实机掉帧时可整体替换演出实现而不动学习流。
3. 同步域与学习流域解耦：学习流只产生事件、消费物化状态；同步契约见实现决策 S1。
4. server 各域互不依赖，共享数据模型；server **不做调度**（离线优先决定调度只能在客户端）。引擎的两个函数要分清：**调度器**（状态→计划/抽卡，仅客户端）与**折叠器**（事件→状态投影，客户端权威＋服务端同构投影）——server 只复刻后者，永不复刻前者（S1-3/S2）。

## 用户故事（编号，尽量穷尽；括号＝需求锚点）

- US-01（R1/R11）：孩子首次使用选起点（0 起步/1上…6下），系统装载对应学期包；追加学期包只发新包不改代码。
- US-02（R2）：孩子沿拼读主线推进，阶段过关率 ≥80% 解锁下一阶段；四线卡片共用同一调度引擎与统一「卡」抽象。
- US-03（R3/E1）：每答一题，引擎按正误×反应时判定熟练度：快对升档、答错降一档；P5 连续 2 轮快对毕业，毕业后每月 10% 抽样回池。
- US-04（R4/E4/E5）：打开即得当日计划——**v1.1＝双段时间盒**：新词段 ≤10 分钟（音节块拼读支架，新词量带内自适应）＋复习段 ≤5 分钟（答题驱动射击，时间盒主控到点即停顺延），周末只复习；超容按到期时间＋错误次数截断；中途退出断点续学；提醒窗口内完成得宝箱。（v1.0 的「1 关 15 分钟＝新词 5-8∶复习 15-18」单关结构由 S9 双段日计划取代，详见 S9）
- US-05（R5/E2/E6）：每池呈现绑定题型，变式三档按近 3 次快对率自动选档；连错 2 次插缓冲题、连错 3 题插低难度题；拼写答错展示正确拼写 3 秒；拼写键盘 QWERTY 大按键、有效字母集合高亮且不提示顺序。
- US-06（R6）：音近词引入日隔开 ≥3 天；复习期出音近对比辨析卡与词族串烧。
- US-07（R7）：情景探索页点击物品热点出词卡（图/词/发音/加入今日学习）；孩子界面任何位置不出现音标。
- US-08（R8）：拼写答对操控战机射击怪兽，连对 3 题充能大招；打卡攒碎片，碎片＋星星双消耗解锁战机/涂装；无答题不产生子弹（无免费游玩模式）；boss 段不达标换易变式重来，永不判失败。
- US-09（R9）：课时制＋关末休息提示；每周 1 张补签卡。
- US-10（R10）：≥2 个孩子档案，主界面头像即切，各自独立进度/起点/**词包选择（含家庭自定义包）**/机库；儿童切换无门禁，家长区有门禁。
- US-11（R12/E7）：家长下载 xlsx 模板、只填年级/单元/单词三列、上传导入→系统自动补全（音标/释义/例句/emoji/拼读拆分/TTS）→预览确认（ECDICT 查无标黄进待补队列）→重复检测→入库（产物＝家庭自定义包新版本，随包拉取进调度）。
- US-12（R13）：词卡发音走系统英文 TTS 儿童慢速档，默认英式可切美式；上线前孩子实听验收，不过关切预录音库保底。

## 实现决策（含已定架构取舍）

### S0 已定面（用户拍板，不重开）

技术栈（Vue3+Vite+Capacitor+PixiJS / FastAPI+SQLAlchemy+SQLite WAL）；七池参数与池-题型绑定（R3/R5 原文）；战机完全取代宠物（T1 关闭）；工具型定位与儿童红线（R18）；自托管部署形态（R15）。

### S1 同步契约细化 ★最高风险决策（辩论记录 debate/01~05）

**契约原则（冻结，R16/E3）**：进度只增不减、冲突合并、离线优先、恢复后自动同步。

**机制决策：事件流联合＋确定性重放（方案 B）**，弃状态快照最大值合并（A）与混合双通道（C）——A 案对照 Anki 同步手册实证（同卡两端作答只保最近状态）文本上不可能满足「只增不减」，且 R5 埋点/R17 周报仍需第二通道；B 案单一机制覆盖同步＋埋点＋周报：

- **同步单位＝学习事件，不是状态行**。事件信封：`{event_id: UUID, child_id, device_id, device_seq, hlc, occurred_at, type, payload}`。事件只追加、永不改写；event_id 全局唯一保证幂等。
- **排序键＝HLC 主序【v2 修订】**：`hlc`＝混合逻辑时钟（物理毫秒＋计数器，设备本地生成；sync 下行携带服务器 HLC 上界供偏移校正）。确定性重放排序键 `(child_id, word_id, hlc, device_id, device_seq)`；墙钟 `occurred_at` 降级为遥测字段，**不参与排序**——设备时钟偏移因此不能打乱合并序（R16 不被打穿）。选 HLC 而非 device_seq 主序：后者跨设备字典序决胜有因果颠倒残留；HLC 保证互见事件必有序（CockroachDB/YugabyteDB 生产先例）。
- **同步动作＝单次双向往返**：客户端 `POST /api/sync` 上行「本地新增事件＋同步游标」，下行「服务器新增事件＋新游标＋服务器 HLC 上界」。客户端把合并后的事件集按排序键重放，重建本地物化状态。任何设备上同一事件集重放结果一致（收敛性），乱序到达不影响终态。
- **「只增不减」的落地语义**：计数类（答题数/正确数/星星/碎片）随事件单调累加；池位＝HLC 全序重放产物——两台设备对同一词的「一升一降」不复写丢失。并发升降并存段默认按 HLC 全序自然合并；「并发段取高池位决胜」列为折叠器规格显式决策点候选（需向量时钟，家庭规模收益低，golden 向量先覆盖再裁）。
- **折叠器＝共享规格【v2 修订】**：「事件集→物化状态」折叠器输出共享规格文档；TypeScript（客户端权威）与 Python（服务端周报投影）同构实现，跑同一套共享事件向量 golden 测试断言同终态（向量集必含：升×降×时钟偏斜×并发升降）。**折叠≠调度**：server 只做投影，不实现计划/抽卡/变式选档。
- **内容包不同步、只拉取**：词包版本化不可变（发布后不改，改＝新版本号），客户端下载缓存＋完整性校验（清单含逐文件 SHA-256），旧版本保留至新版本校验通过后清理。
- **触发时机**：App 前台恢复、学习单元结束、手动下拉、网络恢复事件；失败静默重试退避。**前台语义实现约定【v2 注记】**：60 秒同步窗口在 App 前台/回前台语义下保证（iOS 挂起态无后台执行权）；E3 措辞修订已于 2026-10-24 G3 获用户确认（冻结文本同步更新）。

### S2 调度引擎语言与落位

引擎＝**客户端 TypeScript 纯函数模块**（零 I/O、零框架依赖，vitest 单测＋性质测试）。调度器（状态→计划/抽卡）与折叠器（事件→状态投影）是两个函数：调度器仅客户端；折叠器双端同构（S1）。server 不复刻调度，只对事件做折叠投影（周报聚合，只读，不写回卡池状态表）。理由：离线优先（R14/R16）决定排课/抽卡/升退档必须在无网设备上完成；Vue3 栈下唯一单实现选项就是 TS。

### S3 词表编制流水线落位

流水线＝**server 侧 Python 模块，双入口共用**：编制批量走 CLI（内容工程：收集→三列 xlsx→ECDICT 补全→预览→入库），家长自定义走 HTTP API（R12 同链路）。ECDICT（约 77 万词条）整库导入 server 本地 SQLite 只读表作自动补全主源——**预载在服务安装期独占执行**，运行期只读；查无进待补队列（E7）。补全项：音标/释义/模板例句/emoji 配图/拼读拆分；TTS 发音不落库（设备端实时合成）。

**写拓扑（SQLite 单写者）【v2 修订】**：uvicorn 单进程＋单写连接（应用内天然队列化，批量导入与 sync 写共享同一写连接串行）；读连接可并发（WAL 读写不互阻塞）；busy_timeout 显式 ≥5000ms 兜底；**禁用 FastAPI 多 worker 共写**（SQLITE_BUSY 实证先例）。

### S4 家长区鉴权形状

- 服务器：装机时生成本机**家庭令牌**（一次性手工配置到各设备），除 healthz 外全部 API 校验令牌头。威胁模型＝家庭局域网/Tailscale 内网（R15 不暴露公网），不做账号体系（非目标）。
- 客户端家长区：两位数算术门禁（E8）＝UI 层门禁，通过前儿童进度界面零渲染。
- 已知取舍：家长 API 与同步 API 共用同一令牌，未分权——内网威胁模型下可接受，**有主技术债**：若未来暴露面变化（商业化/公网），升级为独立家长凭据（登记延期票）。

### S5 PixiJS 演出层边界（任务参数设计缝）

- 演出域＝独立画布组件，与 Vue 应用树并存而非内嵌于题型组件；契约三向：`答题结果 →（开火/命中/连击/充能事件）→ 演出完成回调`。演出组件**不 import** 题库/引擎/同步任何模块。
- 奖励资产状态（星星/碎片/连击）由学习流域记账，演出层只收指令发事件，不持业务状态。
- 替换缝：契约保持稳定前提下，演出实现可整体替换（PixiJS→Cocos 场景嵌入），接口不变。

### S6 发音

TTS 抽象接口两后端：①系统英文 TTS 慢速档（设备侧、离线可用），默认英式可切美式；②预录音库（词包附带音频，保底）。默认走①；R13 实听验收不过关时对失败词切②。音标仅存词库供家长端/管理界面显示，孩子界面零音标（R7）。

### S9 双段日计划与自适应新词量【v1.1 新增，2026-10-24 用户拍板；v1.2 修订新词段交互，2026-11-01 用户拍板】

- **来源**：用户想法（新词分音节背诵自适应增量 ≤10 分钟＋旧词战机复习 ≤5 分钟）→ 调研报告 `reports/09-每日计划双段改造调研.md`（四路检索＋正反质疑轮）→ AskUserQuestion 四决策全按推荐项通过（pending-confirmations P-06）。R4 措辞修订已同步冻结件（同 E3 先例）。**v1.2 来源**：用户实测后新想法（字母名朗读链＋字母填空拼回＋大字横线视觉）→ 竞品调研（Duolingo ABC/Khan Kids 均以缺失字母填空为核心题型；字母名＋音同教优于只教音；b/d 镜像混淆 5-7 岁发育正常）→ 两决策拍板（P-08）。
- **日结构（取代 v1.0 单关结构，为引擎 planDailyLevel 之上的 day 层编排）**：
  1. **新词段 ≤10 分钟**＝「读→拼」两阶段（v1.2）：**读阶段**＝大字整词四线三格呈现（音节下加横线标注分段）＋Q 版箭头引导至下一行音节块框（词卡按音节块分色，由 word_versions 拼读拆分字段驱动；**无拆分数据的词整词呈现**，宁缺勿滥）→ 音节块逐块点读 → **字母名朗读链**（同日用户补正定形）：逐音节拼读——每音节先逐字母读字母名再读音节音（h e l→hel、l o→lo），音节读完读整词（hello）；无拆分词＝逐字母→整词（TTS 串行队列，正常语速）。**拼阶段**＝字母填空拼回整词：整词变四线格空格（一格一字母）→自动读整词→逐格从正确字母＋2-3 干扰字母中选填（干扰优先取词内字母的镜像易混组 b/d/p/q，次取词内其他字母，不足随机；选错打乱选项重来，连错 2 次正确字母轻微高亮防挫败）；填完→整词朗读＋随机英语表扬语（≥5 条预设，混过程性表扬）。**考核面＝字母拼写产出（retrieval practice），不考核音节切分知识**（P-06 决策 1 不变；填空首试正确率进段消化指数信号，补 v1.1「正确率权重最高但新词段无信号源」缺口）。段尾 boss 收官（沿用 boss=本段词表）。**完成页「再学一次」**（v1.2 同日增补，P-09）：done 页提供同批卡原地重学入口——重建会话（时长沿用原时间盒），**再学不写任何事件**（练习效应会虚高首试正确率污染消化指数、重复 answer 会双次驱动 SRS 池位；家长侧暂不可见再学行为，属已知代价，P-09 决策 2）。
  2. **复习段 ≤5 分钟**＝「雷霆战机」拼写驱动射击（**v1.4 仿真度重制，2026-11-02 用户实测反馈 P-11**：票 29 v2 反馈密度不足，按雷霆战机调研（腾讯官网 Boss 解析/TapTap 集结测评/space-game 波次结构）仿做相似度 >90%——**演出面 v3**：双层星空滚动卷轴；window 级指针拖动战机横移（lerp 跟随，不挡 DOM 考核卡）；**字母级弹幕**（每拼对 1 字母立即 single-fire，词完 burst 扣血＝双层反馈）；波次编队（目标怪＋2 伴飞怪）；**Boss 战**（每 6 词红色警告横幅＋大体型宽血条＋装饰弹幕雨，血量=min(6, 剩余词) 末段必可击破）；**火力升级**（连击驱动武器 Lv1-3：单发→双发→三散射，错误归 Lv1）；击破＝粒子爆炸＋白屏闪光＋震屏＋连击/得分浮字；WebAudio 合成音效（零资产）。**考核面 v1.3 不变**＝字母填空拼写（词只听不显，听写式检索）＋干扰生成器＋洗牌/连错高亮。**语义面不变**：correct=首试全对（review_fill）／重排一次／时间盒·硬顶·顺延；**得分连击纯游戏内**不进事件流；**儿童红线**＝弹幕雨命中战机仅护盾闪烁，无坠机无 game over 无惩罚。「看词选义」与 P0-P2 快过维持 v1.3 取代语义（P-06 决策 3 部分取代，P-10 决策 1）。**时间盒主控**：5 分钟倒计时到点即停，未完成卡按 E4 既有顺延机制滚动；一年级复习段硬上限 10 张（防呆，参数可调）。
  - 段顺序＝新词段→复习段（用户原话顺序）；周末无新词只复习（R4 冻结语义不变）；跳过顺延、加练硬顶、断点续学不变。
- **自适应新词量调节器（纯函数，入引擎域）**：信号＝段消化指数（**正确率权重最高**＋按时完成＋用时在带内）；规则＝连续 3 天指数达标 → +1，任一天正确率 <70% 或超时 → 次日 -1；单日最多 ±1；带内 [3,10]；children 档案每日新词数＝**硬天花板**（家长可锁定固定量，锁定时调节器停用）；每次调整发 `daily_plan_adjusted` 事件进学习事件流（只追加，天然同步可重放），server 端折叠为 adaptation_log 投影供家长域可读。**不引入 FSRS 参数拟合**（单儿童样本量不支持；每日新词量是独立负荷旋钮，与复习调度解耦——FSRS wiki 证据，报告 09 §B）。
- **数据面**：daily_completions 增 planned_new_words/segment_seconds_used（S7）；card_pool_states 零改动（进度锚点不受影响，同步契约不变）。
- **演出契约兼容**：复习段射击复用 S5 三向契约（答题结果→演出指令→完成回调），不新增演出状态面。
- **落地切票**（v1.1 批次）：①引擎 day 层编排＋调节器（纯函数＋单测）；②音节块支架 UI＋TTS 接线；③战机复习段（PixiJS 答题驱动射击＋时间盒）。

- 引擎域：vitest 单测全覆盖（升退档矩阵/配比/截断/变式选档）＋性质测试（任意事件序列重放收敛、毕业条件不变式）。**v1.1 增**：day 层编排（双段结构/时间盒截断/一年级上限）＋自适应调节器（三信号指数/±1 规则/天花板与锁定/事件发出）单测，性质测试扩展至 day 层重放。

- 前端：每票必过 `npm run build`；组件测试覆盖门禁/键盘/词卡关键交互。
- 实机：安卓真机空壳＋首关走查（用户形态实走，收尾纪律 F-12）。
